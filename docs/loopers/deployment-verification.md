# Loopers Deployment Verification

This is the deployment runbook for Base Sepolia rehearsal and Base mainnet. Do not use placeholder values for mainnet.

## Inputs

Required before any deployment:

- Fresh owner/admin wallet address.
- Fresh treasury and royalty receiver address.
- Placeholder metadata URI.
- Allowlist price in wei.
- Public price in wei.
- Allowlist start time.
- Frozen Merkle root.
- RPC URL supplied through `LOOPERS_RPC_URL` or `--rpc-url`.
- Deployer key supplied through `LOOPERS_DEPLOYER_PRIVATE_KEY`.

Example configs live in:

- `packages/contracts/config/base-sepolia.example.json`
- `packages/contracts/config/base-mainnet.example.json`

Copy an example to `*.local.json` before editing. Local config files are ignored by Git.

## Commands

Compile:

```bash
pnpm --filter @helixa/loopers-contracts compile
```

Deploy:

```bash
LOOPERS_RPC_URL="$BASE_SEPOLIA_RPC_URL" \
LOOPERS_DEPLOYER_PRIVATE_KEY="$DEPLOYER_KEY" \
pnpm --filter @helixa/loopers-contracts run deploy -- \
  --config packages/contracts/config/base-sepolia.local.json
```

Deploy and configure sale in one rehearsal run, only when the deployer is also the configured owner:

```bash
LOOPERS_RPC_URL="$BASE_SEPOLIA_RPC_URL" \
LOOPERS_DEPLOYER_PRIVATE_KEY="$DEPLOYER_KEY" \
pnpm --filter @helixa/loopers-contracts run deploy -- \
  --config packages/contracts/config/base-sepolia.local.json \
  --configure-sale
```

Verify:

```bash
LOOPERS_RPC_URL="$BASE_SEPOLIA_RPC_URL" \
pnpm --filter @helixa/loopers-contracts run verify:deployment -- \
  --config packages/contracts/config/base-sepolia.local.json \
  --deployment packages/contracts/deployments/base-sepolia.json
```

## Basescan Checks

After deployment, record:

- Contract address.
- Deploy transaction.
- Optional sale configuration transaction.
- `owner()`.
- `treasury()`.
- `MAX_SUPPLY()`.
- `TEAM_RESERVE()`.
- `ALLOWLIST_WALLET_LIMIT()`.
- `PUBLIC_WALLET_LIMIT()`.
- `MAX_ROYALTY_BPS()`.
- `allowlistStart()`.
- `publicStart()`.
- `saleEnd()`.
- `allowlistPriceWei()`.
- `publicPriceWei()`.
- `merkleRoot()`.
- `royaltyInfo(1, 1000000000000000000)`.

The placeholder URI is constructor-only until a token exists. In rehearsal, mint one allowlist token before reveal and verify `tokenURI(tokenId)` returns the placeholder URI.

## Rehearsal Gates

Base Sepolia rehearsal passes only after:

- Contract tests pass.
- Deployment verification script passes.
- Allowlist proof generated by the API snapshot works against `allowlistMint`.
- Ineligible wallet fails allowlist mint.
- Public mint opens after the 24-hour allowlist phase.
- Reveal cannot run before public start.
- Reveal flips token URI to the shifted final metadata path.
- Pause stops minting but does not stop transfer.
- Withdraw sends ETH to treasury.
- Public supply can close after the sale window.

## Mainnet Gates

Do not deploy mainnet until:

- Fresh owner/admin address is verified twice.
- Treasury/royalty receiver address is verified twice.
- Exact ETH prices are set from launch-time ETH/USD.
- Placeholder Arweave URI is live and checked.
- Final allowlist Merkle root is frozen and backed up.
- Base Sepolia rehearsal has passed from the actual admin wallet path.
